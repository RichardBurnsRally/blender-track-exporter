# 1.0.0-rc.2

Version 1 is a rewrite of the addon. Most concepts from v0.x carry over, but a
lot works differently. To bring an old `.blend` across, see
[Files made with the old addon](../installation.md#files-made-with-the-old-addon):
the **Migrate** button handles most of the changes below for you.

## New

- **Installs as a Blender extension** from its own extension repository, so
  updates show up in Blender. See [Installation & Setup](../installation.md).
- **Much faster exports.** Exporting runs in a compiled core, with work such
  as texture encoding spread across all CPU cores.
- **Several tint sets in one stage.** Tick each of Morning, Noon, Evening and
  Overcast that the stage supports; each has its own weathers. The **RBR Tint
  Set** shader node routes a different input per tint set. See
  [Scene Settings](../scene-settings.md#tint-sets).
- **Shadows.** Baked shadow textures are exported, with **Baking Tools** to
  bake them per tint set and an option to simplify them on export. See
  [Shadows](../shadows.md).
- **Textures are encoded to DDS on export**, from any image Blender can open
  (PNG, TGA, JPEG, …), using each RBR Texture's **Format** and **Mipmap
  Levels**. There's no need to make `.dds` files by hand. Existing `.dds` files
  can still be exported as they are with **Pass through DDS**. See
  [Materials & Shading](../materials.md#rbr-texture-node).
- **Texture addressing:** **Mirror** and **Clamp** per axis, for object blocks,
  super bowl and interactive object visuals.
- **Clouds are previewed** in the viewport sky, from the game's cloud textures.
  See [World Settings](../world-settings.md).
- **Auto Balance** keeps the terrain's reflectance balanced as you change the
  lighting. See [World Settings](../world-settings.md#ground).
- **Fences** are previewed in the viewport by a geometry nodes modifier, can be
  drawn along curves as well as meshes, and can use **custom** tile and pole
  textures. See [Fences & Brake Walls](../objects-fences.md).
- **Instances** (collection instances, geometry nodes instances) export as they
  are. The **Export real instances** option is only needed when each copy's
  modifiers must be evaluated at its own position. See
  [Instances](../object-settings.md#instances).
- **Export errors and warnings** are listed under Export Settings, each with a
  button that jumps to the object, faces or shader node it refers to. See
  [Exporting](../exporting.md).
- An option to **compress** the textures archive. See
  [Exporting](../exporting.md#options).

## Changed

- **Object types are gone.** What an object exports as depends on where it is
  set:
  - **Geometry types** (geom blocks, object blocks, water and reflection
    objects, super bowl, clipping planes, interactive object visuals) are set
    on the **material**, with the RBR Shader node's **Type**. See
    [Materials & Shading](../materials.md).
  - **Mesh types** (static shape collision, interactive objects, fences, water
    splashes) are set on the **mesh**. See [Mesh Types](../objects-mesh.md).
  - The driveline, car location, registration zone and brake wall are picked in
    **Scene Settings ▸ Track Objects**.
  - The sun is picked per World. See [World Settings](../world-settings.md).
- **What gets exported is decided by the view layer**: every object in it is
  exported, including objects hidden in the viewport. To leave objects out, put
  them in a collection excluded from the view layer. See
  [Exporting](../exporting.md).
- **Shader inputs** only read **Attribute**, **RGB**, **Value** and **RBR Tint
  Set** nodes, and textures only come from **RBR Texture** nodes. To use a
  colour attribute (vertex colours), read it with an **Attribute** node; the
  **Color Attribute** node isn't read any more (the migration swaps them for
  you). The old addon
  baked shader node maths into vertex colours on export; anything more involved
  now belongs in geometry nodes: compute it there, store it as an attribute,
  and read that attribute in the material. The optional migration moves
  existing shader node maths into a geometry nodes modifier for you.
- **Collision shading** is a shader input on collision geom blocks, instead of
  the fixed `RBR_SHADOW` vertex colour layer.
- **Driveline events:** start, the two splits, finish and end of stage are
  their own fields on the driveline, not pacenotes. See
  [The Driveline](../objects-driveline.md).
- A camera following a spline is positioned with an **Offset** along it,
  instead of an offset in frames. See [Replay Cameras](../objects-cameras.md).
- **Static shape collision** meshes take their **Physics Properties** preset on
  the mesh. **Soft collision** volumes are empties with **Soft Collision**
  ticked, instead of empties parented to a collision mesh. See
  [Object Settings](../object-settings.md#soft-collision).
- An **interactive object** points at its collision mesh from its own mesh
  settings, instead of having it as a typed child.
- **Wet/water surfaces** are now the **Water Splash** mesh type, with a
  **Weathers** option for all weathers or wet only. See
  [Mesh Types](../objects-mesh.md#water-splash).
- The **brake wall** is a curve, with respawn areas given by a collection,
  instead of a mesh with inner and outer vertex groups. See
  [Fences & Brake Walls](../objects-fences.md#brake-walls).

## Removed

- The per-object **Exported** toggle, and hiding objects to keep them out of
  the export: use the view layer instead (see above).
- **Face map** levels of detail on object blocks.
