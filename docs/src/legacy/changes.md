# Changes from v0.x

Version 1 is a rewrite of the addon. Most concepts carry over, but a lot of
settings have moved, and some work differently. This page lists what changed
for anyone who used the old addon. To bring an old `.blend` across, see
[Files made with the old addon](../installation.md#files-made-with-the-old-addon):
the **Migrate** button does most of what is described here for you.

## Installing

- The addon is a Blender **extension**, for Blender 5.2, installed from its own
  extension repository so updates show up in Blender. See
  [Installation & Setup](../installation.md).
- Export runs in a compiled core shipped inside the extension, with one
  download per platform (Windows, macOS, Linux).

## Scene and export settings

- The export settings (track ID, name, author, particles, surface, country)
  now live in [Scene Settings](../scene-settings.md), alongside the rest of the
  stage setup.
- A stage can have **several tint sets** and **several surface states** at
  once: tick each of Morning, Noon, Evening and Overcast, and each of Dry, Damp
  and Wet, that the stage supports. The old addon had one tint set per scene.
- Each tint set has its own list of weathers.
- The driveline, car location and registration zone are picked in **Scene
  Settings ▸ Track Objects**, not by giving objects a type.
- The scene uses the **Standard** view transform, which the preview shaders are
  made for.

## Object types are gone

The old addon gave every object a type. In v1 what an object exports as
depends on where it is set:

- **Geometry types** (geom blocks, object blocks, water and reflection
  objects, super bowl, clipping planes, interactive object visuals) are set on
  the **material**, with the RBR Shader node's **Type**. See
  [Materials & Shading](../materials.md).
- **Mesh types** (static shape collision, interactive objects, fences, water
  splashes) are set on the **mesh**. See [Mesh Types](../objects-mesh.md).
- **Tint set visibility** stays per object, in
  [Object Settings](../object-settings.md).
- The **Exported** toggle is gone: exclude a collection from the view layer to
  keep objects out of the export.
- The instancer type is gone: instances (collection instances, geometry nodes
  instances) export as they are. The **Export real instances** option is only
  needed when each copy's modifiers must be evaluated at its own position. See
  [Instances](../object-settings.md#instances).
- **Sound triggers** aren't supported yet.

## Materials and textures

- Shader inputs only read **Attribute**, **RGB**, **Value** and **RBR Tint
  Set** nodes, and textures only come from **RBR Texture** nodes. Anything more
  involved, like colour ramps, mixes or maths, belongs in geometry nodes:
  compute it there, store it as an attribute, and read that attribute in the
  material. The optional migration moves existing shader node maths into a
  geometry nodes modifier for you.
- **Vertex Color** nodes are replaced by **Attribute** nodes.
- **RBR Tint Set** nodes route a different input per tint set.
- Each RBR Texture has an explicit **format** (DXT1, DXT1 with 1-bit alpha,
  DXT3, DXT5).
- Collision shading is a shader input on collision geom blocks, not the fixed
  `RBR_SHADOW` vertex colour layer.
- Object blocks no longer use a face map for their level of detail.
- Physical material maps have their own editor. See
  [Physical Materials](../physical-materials.md).

## Worlds

- Sky, cloud and lighting settings live in
  [World Settings](../world-settings.md), and the sky is previewed with the
  **RBR Sky** node.
- The sun is picked per World instead of being a typed object.

## Driveline and cameras

- Start, the two splits, finish and end of stage are their own fields on the
  driveline, not pacenotes. Only **two splits** are supported. See
  [The Driveline](../objects-driveline.md).
- The render distance is set on the driveline's helper, replacing the old ZFar
  object.
- **Look at Car** and **Play Helicam Sound** are camera settings: no need to
  set up a *Track To* constraint by hand for the car. A camera following a
  spline is positioned with an **Offset** along it, instead of an offset in
  frames. See [Replay Cameras](../objects-cameras.md).
- The camera's field of view is treated as vertical, widened to 4:3 for the
  game.

## Collision, fences and brake walls

- Static shape collision meshes take their **Physics Properties** preset on
  the mesh. Soft collision volumes are empties with **Soft Collision** ticked.
- An interactive object points at its collision mesh from its own mesh
  settings.
- Wet surfaces are now the **Water Splash** mesh type.
- Fences pick built-in tile and pole textures, and are generated by a geometry
  nodes modifier. See [Fences & Brake Walls](../objects-fences.md).
- The **brake wall** is a curve with respawn areas, instead of a mesh with
  inner and outer vertex groups.

## Exporting

- Errors and warnings from an export are listed under Export Settings. Each
  has a button that jumps to the object, faces or shader node it refers to.
  See [Exporting](../exporting.md).
- Export options to compress textures and to simplify baked shadows. See
  [Exporting](../exporting.md#options).
