# Mesh Types

For a mesh object, **Object Properties ▸ RBR Object Settings** shows a **Mesh
Type** selector. The type decides how the mesh is exported and which extra
controls appear.

## None

Ordinary visible geometry — the roads, scenery and buildings of the stage. How
it is exported depends on its [materials](./materials.md). With this type you
also get the general **Export real instances** option (see
[Object Settings](./object-settings.md)).

## Interactive Object

Instanced visual geometry for knock-down objects (cones, signs, fences…). It has
both a visible mesh and an invisible collision mesh.

- **Collision Mesh** — the mesh object to use as this object's collision shape.
  Its local geometry is placed with this object's transform; its own position
  is ignored.
- **Physics Properties** — the physical behaviour, chosen from a preset list:
  - **Traffic Cone** — very soft; usable for small signs.
  - **Heavy Concrete Block** — very heavy, can easily kill the car.
  - **Street Sign** — very soft.
  - **Banner Fence**, **Log**, **Log Pole**, **Wooden Fence Bar**, **Wooden
    Fence Pole**.

Only faces whose material's RBR Shader **Type** is **Interactive Object
Visual** are exported as the visible mesh. An interactive object with none is
skipped with a warning.

## Static Shape Collision

An invisible collision shape (no visible geometry). The mesh is stored once and
placed at every instance. Pick the **Physics Properties** preset:

- **Undefined**, **Bush**, **Bendable Tree**, **Tree**, **Tree Stump**, **Tree
  Trunk**, **Metal Barrier**, **Metal Pole**, **Rock**, **Spectator**, **Snow
  Wall**.
- **Spectator** — hitting it ends the stage as a spectator collision.

Some presets reveal more controls:

- **Bush** shows a **Bush Density** (Very Sparse, Sparse, Leafy, Straggly,
  Dense, Very Dense; default Leafy).
- **Tree**, **Tree Trunk**, **Rock**, and **Bush** with Leafy or Straggly
  density show a **Size** (Small / Medium / Large; default Medium).
- Bendable combinations show an info note: **Bendable Tree** "Soft bendable
  collision", **Tree Stump** "Hard bendable collision", small **Rock** "Very
  soft bendable collision".

The same presets are used by [soft collision](./object-settings.md#soft-collision)
empties.

> Collision shapes have hard complexity limits in RBR: at most 30 vertices,
> 84 edges and 56 triangles. This applies to static shapes and interactive
> object collision meshes alike; a mesh over the limit is an export error.
> Keep these meshes simple.

> The export rejects a static shape whose object name contains `CONE` or
> `BANNER_STAND`, and an interactive object whose collision mesh's name
> contains `CONE` (unless it is a **Traffic Cone**) or `BANNER_STAND` (unless it
> is a **Banner Fence**). Rename it.

## Fence

An interactive fence generated by a geometry-nodes modifier. See
[Fences & Brake Walls](./objects-fences.md) for the full controls (fence kind,
vertex colour, tile/pole textures, subdivide).

## Water Splash

A water-splash particle emitter. Each quad face is exported as a splash
surface; other faces are skipped with a warning. Choose when it is active under
**Weathers**:

- **All weathers** — for fords.
- **Wet only** — for puddles that only appear in wet conditions.

It follows the object's tint sets, and its modifiers are applied.
